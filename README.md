# 🌸 Iris Flower Clustering Dashboard

## 📌 Project Overview
The Iris Flower Clustering Dashboard is a Machine Learning project that uses the **K-Means Clustering algorithm** to group Iris flowers based on their physical measurements. The project includes an interactive dashboard developed using Streamlit to visualize clusters and predict the cluster of a new flower.

## 🎯 Objectives
- Apply unsupervised machine learning using K-Means clustering.
- Group flowers based on their measurements.
- Visualize cluster distribution and feature relationships.
- Use Principal Component Analysis (PCA) to display clusters in two dimensions.
- Predict the cluster of a new flower using user-provided measurements.

- Sidebar filters to select clusters.
- Dataset preview table.

## 🧠 Machine Learning Algorithm
**K-Means Clustering** is an unsupervised machine learning algorithm that groups data points into clusters based on their similarity.

The project uses four flower measurements:
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

The measurements are standardized before clustering and prediction.

## ⚙️ Installation and Setup

### 1. Clone the Repository
```bash
git clone https://github.com/YOUR-USERNAME/iris-kmeans-clustering.git
```

Replace `YOUR-USERNAME` with your GitHub username.

### 2. Open the Project Folder
```bash
cd iris-kmeans-clustering
```

### 3. Install Dependencies
```bash
pip install -r requirements.txt
```

### 4. Run the Streamlit Dashboard
```bash
streamlit run app.py
```

The dashboard will open in your web browser.

## 📈 Results
The dashboard displays the clusters generated by the trained K-Means model. Users can explore cluster distributions, compare flower measurements, view PCA visualizations, and predict the cluster of a new flower.

**Note:** Cluster numbers represent group labels and do not directly confirm the Iris species.
